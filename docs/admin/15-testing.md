`tests/run.sh` rebuilds the separate test stack from nothing, runs seven suites and removes it. On 2026-11-14 it passed 708 checks.

| Suite | Checks | What it proves |
| --- | --- | --- |
| Permissions (`tests/permissions.py`) | 397 | every person against every table and action, the tricky cases, accounts and channels, sub-pages and replies, the wikis and publishing, widget layouts and file bytes, search, tasks (viewers read only, assignees in the space, moves and deletes follow the list), polls (viewers vote, one vote each and only their own, closed polls and voted-for choices stay put, moves and deletes follow the poll), forms (viewers answer, one answer each and only their own, answers checked against the questions, only the respondent and editors read an answer, never in the summary, search or audit, questions lock once answered, closed forms stay put, moves and deletes follow the form), links (viewers read only, only http and https addresses, tags tidied by the database, authorship and the list fixed, moves and deletes follow the list), announcements (channels only, viewers read only, end times checked, authorship and the channel fixed, membership and channel deletes followed), and a teeth check that a loosened policy is caught |
| Live (`services/svc/test/live.mjs`) | 25 | notices reach members only, carry no content, follow membership changes; bad, expired and disabled tokens get nothing |
| Accounts (`services/svc/test/accounts.mjs`) | 43 | links are admin-only, single-use and expire; passwords, lockouts, session rotation and replay, sign-out, password changes, disabled accounts |
| Assistant (`services/assistant/test/assistant.mjs`) | 109 | with a stand-in model that records every prompt: restricted content never reaches the model for someone who cannot see it, failover, proposals, meaning search, files, personal keys (which key each call used), search by meaning |
| Collab (`services/collab/test/collab.mjs`) | 36 | refusals (files, task lists, polls, forms, link lists), read-only viewers, live co-editing, sessions closed on losing access |
| Files (`services/files/test/files.mjs`) | 30 | who may upload and download, text from PDF / Word / text, types read from the bytes, risky types never open in place, size limits, deleting |
| Connector (`services/mcp/test/mcp.mjs`) | 68 | the AI-app connector: discovery, registration only for allowed addresses, consent requests checked, single-use codes with PKCE, read-only connections get no writing tools, tools see exactly what the person sees (with a positive control), writes follow the person's role, page edits through live co-editing, refresh rotation and replay, disconnecting, disabled accounts |

The assistant suite uses stand-ins for both the model and the embedder, so tests never call Anthropic or any real model server.

Browser checks (`tests/*-browser.cjs`, `tests/two-browsers.cjs`) drive real browsers against the test stack (`tests/run.sh --keep`): chat, documents, the calendar, proposals, whiteboards, tables, people, the wikis, signing in, files and widgets (`tests/files-widgets-browser.cjs`), search (`tests/search-browser.cjs`), tasks with the calendar and the Home widget (`tests/tasks-browser.cjs`), polls with live votes, a viewer voting, closing and the Home widget (`tests/polls-browser.cjs`), forms with live answers, viewers answering but not seeing each other's answers, locked questions, CSV, copying to Sheets, closing and the Home widget (`tests/forms-browser.cjs`), links added and changed live, tag and word filters, a refused javascript: address, a viewer's read-only list and the Home widget (`tests/links-browser.cjs`), announcements posted, edited, ended and shown again live, pinned in the channel's chat, a refused past end time, a viewer's read-only view and the Home widget (`tests/announcements-browser.cjs`), the connector's consent screen and Connected apps (`tests/connect-browser.cjs`) (`tests/accounts-browser.cjs`, on the public door at 3210). Run them from a folder where Playwright is installed (`npm install playwright`).
