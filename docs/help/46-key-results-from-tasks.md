---
title: Key results from tasks
parent: Weft help
summary: Let a key result in Goals count the done tasks in a task list, so its progress moves by itself as tasks are ticked off.
---
A key result in **Goals** does not have to be a number someone types. It can follow a **task list** in the same channel: it counts how many of the list's tasks are done out of all of them ("5 of 8 tasks done"), and its progress moves whenever someone ticks a task off, reopens one, adds one or deletes one. Nobody has to remember to update it.

### Counting from a task list

1. Open the goal set in **Goals**. Under a goal, press **Add a key result** (or **Edit** on one you already have).
2. In **Count from**, pick **Done tasks in** and the list. Only task lists in the same channel as the goal set are offered. If the key result has no title yet, Weft fills one in for you; you can change it.
3. Press **Add key result** or **Save**.

The key result then shows "3 of 8 tasks done" and its percentage, says **Counts from** and the name of the list (press the name to open the list), and has no **Update** box. It shows who changed it last: whoever ticked off the last task, including someone ticking off a task that was given to them. A list with no tasks yet counts as 0 %.

### Going back to typed numbers

Press **Edit** on the key result and pick **Numbers typed by hand** in **Count from**, then **Save**. It keeps the numbers the list last gave and you update it by hand from then on.

A key result also stops counting by itself, keeping its last numbers, if the task list is deleted, or if the list or the goal set moves to a different channel.

### Who can do what

Everyone in the channel sees which list a key result counts from and how far along it is; nobody else does. Editors and owners link a key result to a list, change it or go back to typed numbers. Viewers cannot, but ticking off a task that was given to them still moves the key result. Weft can read the numbers to answer questions, but it cannot change them.
