---
title: Task from a message
parent: Weft help
summary: Turn any chat message into a task in one of the channel's task lists, with a link back to the message.
---
When someone asks for something in chat ("Can someone fix the gate sign?"), you can turn that message into a task straight away, so it does not get lost further up the conversation.

### How to use it

- In a channel (or your Personal space), point at a message and press **Make a task** under it. On a phone or tablet the button is always shown.
- **Add a task** opens under the message. The task's name is the message text; change it if you like (up to 300 characters).
- Pick the **Task list** it goes in. Only task lists in the same channel are offered. If the channel has none yet, Weft offers **A new list called Tasks** and makes it for you.
- Choose who does it and a due date if you want, then press **Add task**. **Cancel** (or Esc) closes the form without adding anything.
- The message then shows **Task open in** and the list's name, and **Task done** once someone ticks it off. Press it to open the list.
- In **Tasks**, the task shows **From a message**. Press it to jump back to the message in chat.

The task is an ordinary task: you can rename it, assign it, give it a date, comment on it or tick it off like any other. Changing the task does not change the message, and the other way round.

### Who can see what

- Editors and owners of the channel can make a task from a message, anyone's message. Viewers do not see **Make a task**, but they see which messages became tasks.
- The task belongs to its list, so everyone in the channel can see it, and nobody else, not in search and not in Weft's answers.
- A task can only link to a message in its own channel.
- If the message is deleted, the task stays; it just no longer says **From a message**.
- If the task list is moved to another channel, its tasks go with it but lose their link to the message, which stays where it was.
- Weft (the assistant) can read these tasks for people who can see the list. It cannot make them from messages.
