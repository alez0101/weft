title: Last retro's actions
parent: Weft help
summary: A new retro starts with the previous retro's actions and whether their tasks got done, so the team checks follow-through first.
---
When you open a retro in **Retros**, a box called **Last retro's actions** sits above the three columns. It lists the actions from the previous retro in the same channel, so the first thing the team talks about is whether last time's plans actually happened. It is part of **Retros**; there is nothing to switch on.

### What you see

- **From** names the previous retro and its period. Press the name to open it. The previous retro is the newest one in the same channel that was made before this one.
- Each action shows where it got to: **Done**, **Open** (with who it is for and when it is due), **Late** (open and past its due date) or **Not a task** (nobody turned it into a task).
- A line counts them, such as "3 actions: 1 done, 1 still open, 1 never made a task".
- The first retro in a channel has no box, since there is nothing to look back at. If the last retro had no actions, the box says so.
- Changes show up at once, without reloading: a task ticked off in Tasks, Boards or here, or a new note.

### Following up

- **Carry over** puts an action that is not done into this retro's **Actions** column, as a new note in your name. Once it is there, the row says **In this retro** instead. Anyone in the channel can carry an action over, viewers too, just as anyone can add a note.
- Editors and owners, and the person a task is for, can tick a task done from the box. Others see the tick box but cannot change it.

### Who can see what

The box shows only what you could already see in the previous retro: people in the channel see it, nobody else does. It never says who wrote an action, so anonymous actions stay anonymous (a carried-over action does carry the name of the person who carried it). If a retro is moved to another channel, its box looks back at the previous retro in its new channel. Weft (the assistant) can read the same actions you can and cannot change them.
